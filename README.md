# smoovplay.github.io

SmoovPlay's website: the home page and How it works & FAQ, served by GitHub Pages from `main`. Plain HTML, CSS and a
little JavaScript, with no build step.

Videos and stills load from the comparison page ([smoovplay/compare](https://github.com/smoovplay/compare)), so none
are stored here. The diagrams in `assets/` are SmoovPlay's own, from its README.

SmoovPlay itself: https://github.com/smoovplay/smoovplay
